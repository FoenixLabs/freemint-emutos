Copy the CONTENTS of this folder to the root of FAT32 D:, merging folders.
MINT/MINT.CNF enables fVDI RGB565, then XaAES and TeraDesk.
Requires DDR-aware EmuTOS; the existing FreeMiNT kernel on C: is unchanged.
MINT/MONO.CNF restores monochrome; MINT/SHELL.CNF restores shell recovery.
MINT/FVDI/README.TXT covers diagnostics, cache/VDMA validation and recovery.
DESKTOP/DESKTOP.PRG includes Foenix-specific Video Options.
This folder does not include or overwrite your TERADESK.INF settings.
MINT/SOURCE contains matching source archives, patches and rebuild scripts.
