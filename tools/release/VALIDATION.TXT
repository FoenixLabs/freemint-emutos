A2560Me validation, 2026-10-17
============================

Passed on physical target through RM-10 observation and vendor debug:
- DDR-aware EmuTOS RAM boot; alternate RAM appears in FreeMiNT meminfo.
- 4 MiB alternate-RAM pattern and allocation/reservation bounds diagnostic.
- Eight RGB565 colour bars, expected colour order and monochrome restore.
- Cache-coherent VDMA copy/fill, CPU cached readback and both overlap directions.
- Colour XaAES/TeraDesk boot, text, directories, dialogs and overlapping redraw.
- Physical keyboard/mouse input; user reports responsive dragging with no
  corruption after cache/VDMA changes (qualitative, not a benchmark).
- Video Options: current 1280x960 16 bpp; RGB565 1280x960/640x480 and
  monochrome 1280x960, no invalid Atari shifter choices.
- Main ROM flash at 0xFFD00000, vendor verify, independent full readback
  identical to the supplied image, and normal colour desktop boot.

Host validation: DDR failure paths/preservation, production video register
transitions, DMA descriptors/bounds/overlap/busy/error/timeouts, mode list,
no FPU/STOP in checked objects, binary identities/headers/configuration,
offline custom desktop rebuild matches, drive/release checksums.
Fresh build from the EmuTOS source snapshot and supplied MiNTLib archive
produced byte-identical FLASH, RAM-test and SRAM-recovery ROMs.

Not validated: all DDR cells, long-duration stress, half-resolution switching,
1280x1024 timing, arbitrary hardware revisions or third-party applications.
Legacy console text can be hidden behind colour scanout; use shell recovery
for visible diagnostic output. This is an experimental board-specific port.

Raw lab logs, credentials, serial captures, private settings and prior flash
contents are deliberately not included in this distribution.
